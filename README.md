## Delivery principles

- **Evidence before claims:** no invented ROI, saved hours, or success metrics.
- **Human control:** approvals stay explicit around sensitive or irreversible actions.
- **Privacy by design:** secrets and client data never belong in public artifacts.
- **Operational quality:** tests, CI, documentation, and clear failure behavior ship with code.
